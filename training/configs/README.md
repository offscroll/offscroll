# OffScroll Training Configs

100 randomly-generated OffScroll configuration files for layout
optimization training. Each represents a plausible newspaper with
a different content mix.

Generated by Belle (IRAS #171) on 2026-03-29.

## Generation Strategy

**20 archetypes, 5 configs each = 100 total.**

Each archetype defines category weights that bias feed selection
toward a coherent newspaper personality. Weighted random sampling
(without replacement) selects 10–30 feeds per config. Off-category
feeds have a small inclusion probability to prevent configs from
being too uniform.

## Additional Variance

Beyond archetype-driven feed selection, each config also randomizes:
- **Newspaper name** — generated from adjective + noun templates
- **Page target** — 6, 8, 10, 12, 14, or 16 pages
- **Column count** — 2, 3, or 4 columns
- **Page size** — letter or A4
- **Curation weights** — randomized 0.5–1.5 for each dimension
- **Compile schedule** — random day and time

## Corpus Validation

641 feeds validated from the original 659-feed corpus (#170).
18 feeds removed (2.7%):
- 14 SSL certificate failures (mostly Medium-hosted engineering blogs)
- 4 HTTP 429 rate limits

Attrition was below Claire's 5–15% estimate. The SSL failures are
likely alive but use certificate chains not trusted in the validation
environment. Conservative to remove them for training purposes.

- **Content profiles across all configs:** mixed 46%, text-heavy 38%, image-heavy 16%
- **Post frequency across all configs:** daily 44%, weekly 41%, irregular 15%
- **Category coverage:** all 33 corpus categories represented
